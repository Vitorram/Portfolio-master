# Portfolio — Vitor Menezes

Portfolio pessoal para apresentação de projetos, habilidades e trajetória como desenvolvedor.

## Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS

## Objetivo

Centralizar projetos relevantes e facilitar o acesso a demonstrações, código-fonte e informações profissionais.

## Desenvolvimento local


```bash
npm install
npm run dev
```

A aplicação fica disponível em `http://localhost:3000`.

## Projeto em destaque

Os projetos apresentados no portfolio incluem aplicações backend, APIs REST, projetos Java, frontend e experimentos com Inteligência Artificial.
